# apis_imagens

**Aluno:** Guilherme Valadares

App Flutter da aula prática **APIs Divertidas em Flutter** (Móveis I), que busca dados reais em três APIs públicas e gratuitas.

| Tela | API | O que faz |
| --- | --- | --- |
| Galeria de cães | [Dog CEO](https://dog.ceo/dog-api/documentation/) | Sorteia uma foto da raça escolhida e conta as fotos sorteadas |
| Pokédex | [PokéAPI](https://pokeapi.co/docs/v2) | Busca por nome ou número, ou sorteia entre 1 e 151, e mostra ID, imagem, tipos, altura e peso |
| Personagens | [Rick and Morty API](https://rickandmortyapi.com/documentation) | Lista com filtro por status, paginação e detalhe, com favorito salvo no aparelho |
